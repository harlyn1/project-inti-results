Project Inti (codename) pilot results

The real benchmark run through the Project Inti Runner. Eight models, the same 73 persona×goal pairs each (seed 20261116). All 53 criteria, each judged by its own validated judge through the Batch API.

Models and status

Overall pass rate is passed / (passed + failed) over judged, applicable conversations. Conversation cost, tokens, and wall-clock are per-conversation averages. See the notes under the table.

ModelProviderStatusOverall pass % (95% CI)verdicts (n)Conv cost (avg)Tokens / convWall / conv

95% CI is the Wilson score interval on the overall pass rate, computed from the model's pass count and its number of judged, applicable verdicts (n). Models with a smaller n have wider intervals.

Conversation cost is the average spend on the model under test across its 73 conversations, from measured prompt and completion tokens. The four Anthropic models are priced exactly from the Runner's own pricing table (standard tier). The four OpenRouter models are not in that table, so their cost is an estimate (marked "est") using the nearest in-table analog: gpt-6.1-terra-pro at GPT-5 rates (1.25 / 10.00 per Mtok in/out), gemini-4-carbon and gemini-4-argon at Gemini-3-Pro rates (2.00 / 12.00), and kimi-k3.1-pro at a generic large-open-model assumption (0.60 / 2.50). Treat the estimates as order-of-magnitude, not billed amounts.

Wall / conv is average wall-clock per conversation for the job. Per-call latency was not instrumented in this run, so this is throughput, not single-request latency. The four OpenRouter models' figures are inflated by a mid-run credit outage and the resume cycles that followed, so they are not comparable to the four Anthropic-direct models.

Fine-tune impact: Qwen3-4B on the five weakest criteria

An experimental LoRA fine-tune of Qwen3-4B (r=16, 3 epochs, ~127 MB adapter), trained on synthetic data for the five criteria where every model scores lowest, plus abstention and grounding examples aimed at cutting fabrication. Evaluated on a held-out set of 40 single-turn prompts (8 per criterion), base versus tuned.

Fabrication probe

Eight traps that each ask for an exact, unverifiable program fact (a scholarship deadline, a tuition figure, a bootcamp pass rate). A pass means the model declines or redirects to an official source without inventing a number.

Gap-closure on the five weakest criteria

Judge: claude-sonnet-4-6, scoring base and tuned replies on identical prompts, 8 applicable per criterion. Hover a criterion name for its definition.

Method and caveats. These Qwen numbers come from single-turn held-out prompts judged by Sonnet as a proxy, not from the official multi-turn protocol or the validated per-criterion judges. The "big models (official avg)" column is the mean of the eight pilot models' official pass rates on each criterion, shown as context, not a like-for-like comparison. For grounded next-step the official judge uses an external pathways tool that cannot be reproduced offline, so that row is a loose proxy. "Not engaged" means the judge found the base model's replies did not address the decision, so no applicable items.

The tune pushed the 4B model toward a coaching style: it now opens with a reflective question and engages the decision, which drove the gains on coaching questions and need-to-haves and cut fabrication. The same new caution ("at a high level...") stopped it from naming concrete job-specific skills, which collapsed skill alignment. A coherent specialization trade-off rather than a uniform win.
